# Захар & Валерия · 27.01.2027

Свадебное приглашение — статичный сайт для GitHub Pages.

- `index.html` — страница (дизайн и анимации), интро-видео при загрузке, анкета гостя.
- `assets/intro.mp4` — интро (проигрывается без звука и плеера, затем плавно открывается главный экран).
- `assets/img`, `assets/fonts` — изображения (WebP) и шрифт Forum.
- `apps-script/Code.gs` — приём ответов анкеты в Google Таблицу «Свадьба Захар и Валерия — анкета гостей» (лист «Ответы»).

## Анкета

Форма отправляет JSON (`name`, `attendance`, `family`) POST-запросом на веб-приложение Google Apps Script,
адрес — константа `RSVP_ENDPOINT` в `index.html`. В поле «пара / семья» можно вписать несколько имён,
каждое с новой строки — поле растёт до 6 строк.

Если код скрипта меняется: Apps Script → «Начать развертывание» → «Управление развертываниями» →
редактировать → «Новая версия» (URL при этом не меняется).
